# SOLE (メンズサロン) LP 運用ルール

## プロジェクト概要
岡山市南区のメンズ専門サロン「SOLE」の公式ランディングページ・Webサイト。

## 基本方針
1. **洗練されたブランドイメージの維持**: メンズサロンとしての高級感・清潔感・スタイリッシュさを保つ。
2. **ノーコスト運用**: GitHub Pages等を活用した安定・無料運用。
3. **本番更新の徹底**: 修正後は「本番更新.bat」またはgit pushによる本番反映を必ず検証する。

## コード変更時の絶対原則
コード変更時は、レスポンシブ表示（スマートフォン・PC）のレイアウト崩れやリンク切れがないかを徹底検証すること。
